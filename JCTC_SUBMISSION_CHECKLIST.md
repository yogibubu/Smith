# SMITH - JCTC submission checklist

Prepared for the *Journal of Chemical Theory and Computation* as an ACS
**Article**.

## Ready

- [x] JCTC `achemso` manuscript class (`journal=jctcce`, `manuscript=article`).
- [x] Concise four-sentence abstract.
- [x] Complete Supporting Information description in the manuscript.
- [x] Data and Code Availability statement with public repository.
- [x] Explicit author-contribution, funding and competing-interest statements.
- [x] Cover letter identifying significance, Article type and post-arXiv changes.
- [x] TOC graphic in a 3.33 x 1.88 inch submission canvas.
- [x] Versioned SMITH 0.1.0rc7 source and validated release artifacts.

## Final portal checks

- [ ] Add the arXiv identifier if it is assigned before the ACS submission is finalized.
- [ ] Enter the same Data and Code Availability statement in ACS Publishing Center.
- [ ] Report that no external funding supported the work.
- [ ] Confirm the no-competing-financial-interest declaration.
- [ ] Select and conflict-check any suggested reviewers directly in the portal.
- [ ] Confirm author metadata, telephone number and ORCID.
- [ ] Inspect and approve the ACS-generated manuscript proof and TOC preview.

## Submission files

- `main.pdf` and the LaTeX source tree.
- `supporting_information.pdf` as Supporting Information for Publication.
- `cover_letter.pdf`.
- `figures/graphical_toc.png` as the TOC graphic.
- `JCTC_SUBMISSION_CHECKLIST.md` for the author's local final gate only.
