# SMITH release artifacts

The versioned archives in this directory are generated by
`scripts/build_release_bundles.py`.  The arXiv source archive is written under
`arxiv/`; the reviewer bundle contains the manuscript, Supporting Information,
and standalone manual; the standalone bundle contains the wheel, source
distribution, manual, and acceptance record.  Every archive carries its own
`SHA256SUMS` manifest.

The original `SMITH_arxiv_v1.zip` is the immutable source of the first arXiv
submission and is not overwritten by release-candidate builds.
