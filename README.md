# SMITH / SONIC manuscript

Working LaTeX draft for the SMITH coordinate-construction manuscript and the
SONIC coordinate family.

Build:

```bash
latexmk -pdf main.tex
latexmk -pdf supporting_information.tex
latexmk -pdf graphical_toc.tex
latexmk -pdf cover_letter.tex
```

The final ACS portal checks are tracked in `JCTC_SUBMISSION_CHECKLIST.md`.

The draft is intentionally source-close: the implementation-status table tracks
the current SMITH/SONIC code paths, including the special-coordinate fragment
model and the active pseudo-bond / pseudo-cycle branch.

The manuscript is deliberately limited to coordinate construction, reporting,
first derivatives, and external serialization.  Optimizers, finite
internal-to-Cartesian realization, force fields, Hessian transport, and
higher-order derivatives are outside the SMITH boundary.

The construction and B-matrix timing microbenchmark is tracked in
`data/construction_scaling_benchmark.json` and can be regenerated with:

```bash
export MATRIX_ROOT=/path/to/your/MATRIX
python scripts/run_construction_scaling_benchmark.py
```

`MATRIX_ROOT` is supplied by the user; no developer-machine path is assumed.

The local-pseudosymmetry validation (globally C1/local C3v center, substituted
and fused rings, CN 5--9 ideal/distorted templates, generic CN 10/12 fallback,
distorted SF6 and square-antiprismatic [ZrF8]4-, rotation/permutation
invariance, ambiguity handling, and the Fortran control path) is
tracked in `data/local_salc_validation.json` and can be regenerated with:

```bash
export MATRIX_ROOT=/path/to/your/MATRIX
python scripts/run_local_salc_validation.py
```

The regression corpus additionally retains the supplied pagodane (`C20H20`)
and indane (`C9H10`) structures as demanding ring fixtures.
They test full-rank PIC/SONIC construction, the complete analytic-versus-finite-
difference SONIC B matrix, fused/caged ring families, and representative
positive/negative Cartesian motions.  The release gate now generates every one
of the 114 pagodane and 51 indane motions, checks the constant-B contract and
loads every trajectory through the GUI data model.  Motion manifests include
the Euclidean or optional mass-weighted right-inverse metric, explicit mass
provenance, full-topology check count, local/global symmetry labels,
conditioning and localization diagnostics, plus ordered-ring/component
metadata; display
amplitude is normalized independently in ångström.

The graphical table-of-contents image is generated by:

```bash
python scripts/build_graphical_toc.py
```

The validation molecule panel is generated by:

```bash
python scripts/build_molecule_panel.py
```

The introductory coordinate atlas and the dedicated special-coordinate
structure gallery are generated from the tracked molecular fixtures by:

```bash
python scripts/build_coordinate_figures.py
```

After building the wheel and source distribution in a temporary directory,
the manuscript, reviewer, and standalone release archives are generated by:

```bash
python scripts/build_release_bundles.py --dist-dir /absolute/path/to/dist
```

The Supporting Information norbornane example is the explicit Gaussian 16
Rev. C.01 compatibility route.  From the minimal extended-XYZ file:

```bash
smith-sonic build si/norbornane_smith_input.xyzin /path/to/output/norbornane.xyzin
```

The command also writes the coordinate report and the Gaussian 16 input beside
the chosen output path.  The Gaussian 16 Rev. C.01 profile is enabled by
default; no functionality available only in a development version is used.

## Standalone publication package

The `standalone/` directory is a self-contained, revision-pinned distribution
of the SMITH/SONIC builder.  It embeds the ORACLE subset required to perceive
ordinary topology, point-group operations, atom permutations and primitive
coordinates from Cartesian input, and can consume richer frozen sections from
any provider.  In MATRIX, ORACLE remains authoritative and SMITH performs no
reperception.  No second repository is required to install or run the
standalone package.

Install a local checkout and run the supplied examples with:

```bash
python -m pip install ./standalone
smith-sonic example water /tmp/water.xyzin
smith-sonic inspect /tmp/water.xyzin
smith-sonic example norbornane /tmp/norbornane.xyzin
smith-sonic example formic-acid-water /tmp/formic-acid-water.xyzin
smith-sonic example water-dimer /tmp/water-dimer.xyzin
smith-sonic example benzene-water /tmp/benzene-water.xyzin
smith-sonic example eta3-allyl-palladium /tmp/eta3-allyl-palladium.xyzin
```

Each standalone command also writes a readable `.smith.out` coordinate report
and a Gaussian 16 `.g16.gjf` input.  Gaussian 16 is used as an independent,
general GIC interpreter; SONIC export is one particular use among the many
coordinate definitions supported by that syntax.  The optional export
translates native out-of-plane rows to
improper dihedrals and cannot retain every special composite coordinate; the
native SONIC contract and readable report remain authoritative.

Plain extended XYZ input uses the historically labelled `STANDALONE_MINIMAL`
profile; despite the name, this profile includes molecular symmetry perception.
Inputs may instead carry `TOPOLOGY` or `PRIMITIVES`.  To require a complete,
separately validated state, use:

```bash
smith-sonic build molecule.xyzin molecule.sonic.xyzin --require-frozen-state
```

## Submission freeze

The present standalone candidate has completed external collaborator
validation.  The frozen submission gate comprises a clean installation on
Python 3.11 and 3.13, all four input profiles, the three non-covalent examples,
the eta3 interaction-centre example, Gaussian 16 serialization, and downstream
consumption by LINK and MORPHEUS.  Later methodological development must occur
after this submission snapshot rather than changing it silently.
