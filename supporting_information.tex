\section{Standalone Input and Output Reference}

\subsection{Input schema \texttt{matrix.smith.input.v1}}

The standalone boundary is a standard Cartesian XYZ block followed by optional
\SMITH\ directives.  Four provider-neutral profiles are accepted.  Their
meaning is fixed by the input contract rather than by the program that created
the data.

\begin{table}[htbp]
\centering
\small
\caption{The four standalone input profiles.}
\begin{tabularx}{\linewidth}{@{}p{0.24\linewidth}X@{}}
\toprule
Profile & Required content and action \\
\midrule
\texttt{FROZEN\_STATE} & A complete validated molecular state.  Topology,
symmetry operations, atom permutations, primitive rows and provenance are
consumed unchanged. \\
\texttt{STANDALONE\_TOPOLOGY} & Cartesian geometry and a supplied
\texttt{TOPOLOGY} section.  The pinned standalone frontend constructs the
ordinary redundant primitives. \\
\texttt{STANDALONE\_PRIMITIVES} & Cartesian geometry and a supplied
\texttt{PRIMITIVES} section.  Values, atom indices, Wilson rows and geometry
fingerprints are validated before SONIC construction. \\
\texttt{STANDALONE\_MINIMAL} & Plain Cartesian geometry.  The pinned frontend
constructs covalent topology, cycles, point-group operations with atom
permutations and ordinary primitives. \\
\bottomrule
\end{tabularx}
\end{table}

If \texttt{TOPOLOGY} and \texttt{PRIMITIVES} are both present, their bond rows
must agree.  The output records the selected profile, the source fingerprints
and the accepted construction options.  The minimal route is sufficient for
ordinary molecules; interaction centers, externally audited quasi-symmetry or
special primitives can be supplied through the richer profiles.  This keeps
\SMITH\ operationally standalone while making the perception/construction
boundary explicit.

\subsection{Norbornane input and Gaussian 16 \texttt{ReadAllGIC} export}

The first listing contains only the XYZ geometry and the minimum directives
needed for the compatibility export.  It is not the enriched \texttt{xyzin}
container written after construction.  The complete workflow is

\begin{lstlisting}
python -m matrix smith standalone norbornane_smith_input.xyzin norbornane.xyzin
python -m matrix smith gaussian-input norbornane.xyzin norbornane_g16_readallgic.gjf \
  --title "norbornane SONIC ReadAllGIC optimization" \
  --route "#p hf/sto-3g opt=(readallgic,calcfc,maxcycle=80)"
\end{lstlisting}

The reduced standalone distribution provides the equivalent command
\begin{lstlisting}
smith-sonic build norbornane.smith.xyz norbornane.xyzin
\end{lstlisting}
and writes a human-readable \texttt{.smith.out} report together with the
Gaussian input.

\section{Gaussian 16 Serialization Details}

\subsection{\texttt{ReadAllGIC} route and generated syntax}

Gaussian 16 is used as an external interpreter because its GIC syntax accepts
general symbolic coordinate expressions.  The compatibility route has the
form

\begin{lstlisting}
#p method/basis opt=(readallgic,calcfc,maxcycle=80)
\end{lstlisting}

\texttt{CalcFC} is optional and was used for the direct coordinate-choice
comparison, whereas the three-system solver-consumption table in the main text
uses no initial force-constant calculation.  The generated block is dependency
closed: helper centers and fragment axes precede every expression that uses
them, inactive helpers are emitted as frozen functions, and the complete
rank-closing coordinate set is retained.

\subsection{Terminal translation of native out-of-plane rows}

The native SONIC contract uses the signed curvilinear out-of-plane coordinate

\[
U(j;a,b,c)=\arcsin\!\left[
\frac{\hat r_{ja}\cdot(\hat r_{jb}\times\hat r_{jc})}
{|\hat r_{jb}\times\hat r_{jc}|}\right],
\]

with the stored atom order fixing the sign.  Commercial Gaussian 16 has no
native \(U\) primitive, so serialization alone applies
\(U(I,J,K,L)\mapsto D(J,I,L,K)\).  Multi-\(U\) ring-puckering combinations
remain in the frozen SONIC contract, while the Gaussian file receives their
component periodic dihedrals.  The translation does not redefine the native
coordinate model.  When molecular symmetry is retained, all non-totally
symmetric SONIC rows are written with \texttt{Frozen}; for norbornane this
leaves 15 active \(A_1\) rows and 36 frozen rows in the full 51-coordinate
contract.

\section{Pagodane, Indane and Saccharin Ring-Coordinate Fixtures}

Two Cartesian structures are retained verbatim as publication fixtures.  The
first is pagodane, \(\mathrm{C}_{20}\mathrm{H}_{20}\): the pinned standalone
frontend finds 50 covalent bonds, 11 rings, no aromatic atoms and a
\(D_{2h}\) reference assignment.  The redundant primitive contract and SONIC
basis both have Cartesian rank 114.  The second is indane,
\(\mathrm{C}_{9}\mathrm{H}_{10}\): the frontend finds 20 bonds, two fused
rings, six aromatic atoms and a \(C_s\) reference assignment, while SONIC closes
at rank 51.

The third fixture is planar saccharin, retained specifically as a fused-ring
phase and global-rank regression.  Its \(C_s\) contract contains one butterfly
and five ring-puckering coordinates, all in \(A''\), and closes at rank 45/45.
The generated butterfly is
\begin{equation}
 AppBtFl001=2^{-1/2}\!\left[D(6,1,2,13)-D(16,1,2,3)\right],
\end{equation}
whose relative minus sign supplies the inter-ring direction missing from the
five \(RPck\) rows.  Replacing it by the corresponding sum lowers the rank of
these six rows from six to five.  The regression therefore checks the complete
post-symmetry Cartesian \(\Bmat\), rather than accepting six individually
well-formed but collectively dependent expressions.

Central finite differences of every final SONIC row give maximum absolute
analytic-row errors of \(4.02\times10^{-10}\) for pagodane and
\(4.77\times10^{-10}\) for indane, and \(3.91\times10^{-10}\) for saccharin.
The indane and saccharin sets contain stretch, bend,
cyclic-bend, butterfly and ring-puckering-component families.  All 114 pagodane
and 51 indane display motions are constructed in both signs with the Wilson
matrix frozen at the reference geometry.  They are first-order visualization
artifacts rather than nonlinear internal-to-Cartesian realization services.

Extended independent use by collaborators exposed an important earlier
failure mode.  A dihedral-based representation of endocyclic out-of-plane
deformation did not converge in the back-transformation of a near-planar fused
indane/indene-type scaffold containing one \(sp^3\) CH\(_2\) center.  The
ill-conditioning belonged to the collectively redundant cyclic-dihedral chart
at planarity, not to SONIC rank or symmetry construction.  A native signed
\(U\) source has a finite first-order row at the planar reference and avoids
the dihedral branch ambiguity.  Symmetry projection acts on this oriented
row space and retains both source and target phases; the complete \(\Bmat\)
rank is then checked across all coordinate families.  The indane and
saccharin fixtures are therefore complementary regressions for the change
prompted by independent use.

The version-2 diagnostic manifest records the right-inverse metric, mass
provenance, coordinate conditioning, local domain and pseudogroup, independent
local/global total-symmetry labels, canonical ring order and primitive
coefficients.  A distributed JSON Schema and dependency-free validator define
the machine contract, and the reader remains compatible with archived
version-1 manifests.
