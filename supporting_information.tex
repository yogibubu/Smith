\section*{Norbornane SMITH/SONIC Standalone Input and Gaussian 16 Export}

This Supporting Information records the minimal standalone input required to
generate the norbornane \SONIC\ coordinate contract and the corresponding
commercial Gaussian 16 \texttt{ReadAllGIC} input used in the compatibility
test.  The first listing is intentionally not the enriched \texttt{xyzin}
container written after molecular perception and coordinate construction.  It
contains only a standard XYZ geometry followed by the minimum SMITH directives
needed for this Gaussian-compatible export.  The standalone workflow selects
the commercial Gaussian 16 profile by default, including Gaussian-style
improper-dihedral construction in place of native \SONIC\ out-of-plane rows.
For this one-file example, the standalone package uses its pinned minimal
frontend to supply the graph, cycles, ordinary redundant primitives and their
Wilson B source matrix.  The generated provenance records
\texttt{PERCEPTION\_PROFILE STANDALONE\_MINIMAL}.  The same executable can
instead consume a supplied \texttt{TOPOLOGY} section, a supplied
\texttt{PRIMITIVES} section or a complete externally validated molecular state;
these are input profiles of standalone SMITH rather than dependencies on a
separate application.

The exact standalone workflow is:
\begin{lstlisting}
python -m matrix smith standalone norbornane_smith_input.xyzin norbornane.xyzin
python -m matrix smith gaussian-input norbornane.xyzin norbornane_g16_readallgic.gjf \
  --title "norbornane SONIC ReadAllGIC optimization" \
  --route "#p hf/sto-3g opt=(readallgic,calcfc,maxcycle=80)"
\end{lstlisting}
Equivalently, after installation of MATRIX the console-script shorthand is
\texttt{smith standalone ...} followed by \texttt{smith gaussian-input ...}.
The standalone package distributed with the manuscript constructs the same
contract with \texttt{smith-sonic build norbornane.smith.xyz norbornane.xyzin}
and automatically writes both \texttt{norbornane.smith.out} and
\texttt{norbornane.g16.gjf}.  The default Gaussian 16 profile suppresses active
composite, U-based ring-puckering \SONIC\ rows in the Gaussian file and writes
their terminally translated component periodic \texttt{D(...)} coordinates
instead; the non-redundant \SONIC\ rows remain in
the \texttt{xyzin} contract used for post-processing.

\section*{Advanced Standalone Interface Probes}

The standalone distribution also contains two examples that exercise the
interfaces not covered by a single covalent molecule.  Every build writes
three coordinated artifacts: the frozen \texttt{xyzin} contract, a readable
\texttt{.smith.out} report modeled on the essential coordinate section of the
former Merlino output, and a commercial Gaussian 16 \texttt{ReadAllGIC} input.
The report records the family, reduction class, irrep, active/frozen status,
reference value, native unit, and primitive coefficients of each selected
coordinate.  Non-totally symmetric coordinates are present in the Gaussian
file with the \texttt{Frozen} option; helper center and fragment definitions are
written as inactive Gaussian functions.

\subsection*{$\eta^3$ allyl--palladium interaction center}

The ten-atom idealized allyl--PdCl probe consumes a frozen ORACLE-state fixture.
Its center record has identifier \texttt{C001}, kind
\texttt{ETA3\_CENTER}, and atoms 3--5.  \SMITH\ retains the
Pd--center distance as a protected \texttt{CENTER\_ATOM\_DISTANCE}; the
contract closes at rank \(24/24\) and gives a reference value of
1.8000~\AA.  This is a perception/coordinate interface test rather than an
optimized transition-metal benchmark.

\section*{Pagodane and Indane Ring-Coordinate Fixtures}

Two supplied Cartesian structures are retained verbatim as publication
fixtures in the MATRIX test distribution.  The first is pagodane,
\(\mathrm{C}_{20}\mathrm{H}_{20}\); ORACLE perceives 50 covalent bonds, 11 rings, no aromatic atoms
and a \(D_{2h}\) reference assignment.  Its redundant PIC contract and the
SMITH SONIC basis both have Cartesian rank 114.  The second structure is
indane, \(\mathrm{C}_{9}\mathrm{H}_{10}\); ORACLE perceives 20 bonds, two fused rings, six aromatic
atoms and a \(C_s\) reference assignment, while SMITH closes at rank 51.
The name ``indane'' follows the fused benzene--cyclopentane connectivity of the
provided structure rather than its original generic filename.

Central finite differences of every final SONIC row give maximum absolute
analytic-row errors of \(4.02\times10^{-10}\) for pagodane and
\(4.77\times10^{-10}\) for indane.  The indane set contains stretch, bend,
cyclic-bend, butterfly and ring-puckering-component families.  All 114 pagodane
and all 51 indane motions are constructed in both signs from the pseudoinverse of the B matrix
frozen at the reference geometry.  The resulting Cartesian frames are exactly
symmetric and are checked for the first-order SONIC displacement, unchanged
connectivity, proper orientation, a maximum atom displacement not above
0.10~\AA, and a maximum relative reference-bond change below 0.15.  Every
three-frame XYZ file and Cartesian-vector table is parsed by the GUI data
contract.  The version-2 manifest also records the optional Euclidean or
mass-weighted right-inverse metric, the explicit average/default-isotope/
Hessian/isotopologue mass provenance, coordinate conditioning and localization,
the number of complete ORACLE topology evaluations, local-domain and
local/global total-symmetry labels, and canonical ring order with primitive
coefficients.  A distributed JSON Schema and dependency-free validator define
the current machine contract, while the reader accepts archived version-1
manifests.  Animation amplitude is independent of the mathematical step and is
normalized to a selected maximum atom displacement.  The GUI can filter the
resulting set by family, local domain, local pseudogroup and local or global
total-symmetry character.

\section*{Local-Pseudosymmetry Validation}

The machine-readable results in
\nolinkurl{data/local_salc_validation.json} can be regenerated from an
explicitly selected MATRIX checkout:
\begin{lstlisting}
export MATRIX_ROOT=/path/to/your/MATRIX
python scripts/run_local_salc_validation.py
\end{lstlisting}
The cases comprise the \(C_1/C_{3v}\) methyl probe, benzene, toluene, azulene,
20 ideal/distorted CN 5--9 templates, generic CN 10/12 centers, distorted
\(\mathrm{SF_6}\), and square-antiprismatic \([\mathrm{ZrF_8}]^{4-}\).
Recorded checks include rank, rotation/permutation invariance, template
score/margin and ambiguity fallback, ring/fused-edge behavior, and
Python--Fortran row-space residuals.  Local labels apply only to domains; the
molecular point-group projector remains final.
